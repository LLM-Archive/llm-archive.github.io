# `icons/`

## What you'll see here

Four JPG images — draft variations of a hexagonal "LLM Archive" logo (blue/white, the text "LLM"
over "Archive"). These look like logo-generator or design-tool exports, not something built or
edited by any code in this repo.

## Why it needs to exist

This is a holding folder for logo/icon candidates while the project's visual identity is still
being decided — `logo.png` at the project root appears to be the one currently in use elsewhere
(e.g. `website/`); these four are alternates or earlier drafts. **Nothing in `core/`, `mutable/`,
or `website/` currently references any file in this folder** — if you're looking for the logo
actually used by the site mockups, check `website/mockup.html` and the root `logo.png` first.
